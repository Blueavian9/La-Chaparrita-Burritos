# 🌯 La Chaparrita Burritos Website

A simple, mobile-first marketing website built for La Chaparrita Burritos,
a family-run breakfast pop-up stand in El Sereno, Los Angeles.

Owned and operated by El Sereno natives Delmis and her son Brian, the stand
is known for its $7 authentic breakfast burritos and telera tortas served
outside Elephant Hills Cafe on Huntington Drive — Wed through Sat, 7AM until sold out.

## 🛠 Tech Stack
- HTML5
- CSS3 (custom properties, flexbox, grid)
- No frameworks, no dependencies

## 📦 Dev Environment
- Editor: VS Code
- Version Control: Git Bash + GitHub
- Deploy: GitHub Pages
